## ✨ 주요 기능
1. **100% 검색어 정확 매칭 실시간 검색**: 입력한 검색어와 정확히 일치하는 핀터레스트 결과만 실시간 수집 (무관한 결과 노출 완벽 차단)
2. **사이트 내 100% 핀/고화질 사진/동영상 열람**: 외부 핀터레스트 직접 이동 없이 사이트 내부에서 즉시 시청 및 다운로드
3. **🛡️ AI 빼고 보기 필터**: AI 생성 이미지를 감지하여 걸러내고 실제 사진/창작물만 모아보기
4. **🎯 내 맞춤 알고리즘 피드**: 평소에 검색하고 클릭한 관심사 주제를 학습하여 홈 화면에서 실시간 맞춤 추천
5. **👤 크리에이터 프로필 & 컬렉션 보드 조회**: 핀 작성자의 프로필, 생성 핀, 보드 컬렉션 사이트 내 즉시 열람
6. **🔍 마우스 클릭 위치 클로즈업 줌인**: 클릭한 좌표를 중심으로 정밀 확대 및 패닝
7. **🚫 비슷한 핀 중복 완벽 제거**: 이미지 고유 해시 분석을 통해 중복 리핀 없이 100% 고유한 연관 핀만 추천
